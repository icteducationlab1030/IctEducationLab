# ICT Education Lab Website

## 概要
本プロジェクトは、ICT教育ラボの活動内容、目的、取り組みを紹介するための企業向けWebサイトを構築するための静的サイトです。

本サイトは、教育現場におけるICT活用の推進、学校との連携、研究・実践・発信を支える姿勢を伝えることを目的として設計されています。

## 目的

- 研究室・教育ラボの活動内容を明確に伝える
- 教育現場におけるICT活用の意義を説明する
- 地域・学校・研究者との連携機会を創出する
- お問い合わせや共同研究の窓口を提供する
- プロジェクトの情報をわかりやすく可視化する

## サイト構成

本サイトは、以下の主要セクションで構成されています。

- Top
- About
- Activities
- Contact

各セクションは、企業のコーポレートサイトに近い構成を意識して設計されており、情報の整理性と視認性を重視しています。

## 技術スタック

- HTML5
- CSS3
- JavaScript

本サイトは、外部ライブラリやフレームワークを使用せず、シンプルな静的ページとして構成されています。
これにより、軽量かつ保守しやすい形で運用を進めることができます。

## ディレクトリ構成

```text
IctEducationLab/
├── index.html      # メインのページ構造
├── style.css       # 全体のデザインとレイアウト
├── README.md       # プロジェクト説明書
└── assets/         # 必要に応じて画像や資料を保存するディレクトリ
```

## ローカル環境での確認方法

以下の手順でローカルプレビューを確認できます。

1. このディレクトリに移動します。
2. 次のコマンドを実行します。

```bash
python3 -m http.server 8000
```

3. ブラウザで以下のURLを開きます。

```text
http://localhost:8000
```

## 編集方針

### HTML
`index.html` には、ページの情報構造、見出し、本文、リンク、連絡先情報が含まれます。
新しいセクションの追加や既存コンテンツの修正は、ここで行います。

### CSS
`style.css` では、配色、余白、フォント、ボタン、カードレイアウト、モバイル対応を管理します。
ブランドの印象や利用者の視認性を向上させるために、ここでの調整が重要です。

### JavaScript
必要に応じて、ホバーエフェクトやスクロールアニメーション、フェードインなどの動的な演出を追加できます。

## 運用に関する指針

- コンテンツは簡潔かつ丁寧な表現を基本とする
- 企業サイトとしての信頼性を意識した文言を使用する
- 連絡先や活動内容は正確に更新する
- 実際の活動実績や研究成果が増えた際には、内容を更新する
- 公開前には、文言・誤字・リンクの不備を最終確認する
