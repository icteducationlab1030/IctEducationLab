# ICT Education Lab Website
ICT教育ラボの情報発信を目的とした静的なWebサイトです。
ictラボのGmailにて管理

## 概要
専修大学小田切ラボのwebサイトです。
ICT教育ラボの活動を記録し、外部の方にも向けて活動を発信します。

## 目的

- ラボの活動を記録する
- イベントの告知や発信を行う
- 制作物の共有
- 他SNS等のリンク集
- お問い合わせフォーム等コンタクト方法の記載

## 使用技術

- HTML5
- CSS3
- JavaScript

## ディレクトリ構成

```text
IctEducationLab/
├── index.html
├── style.css
├── README.md
└── assets/        # 必要に応じて画像や資料を格納
```

## ローカルで見る方法

1. このディレクトリに移動します。
2. 次のコマンドを実行してローカルサーバーを起動します。

```bash
python3 -m http.server 8000
```

3. ブラウザで次のURLを開きます。

```text
http://localhost:8000
```

## 制作の流れ

1. 目的を決める
   - どんな人に何を伝えたいかを明確にします。
2. 情報を整理する
   - About, Activities, Contact など、必要なセクションを洗い出します。
3. デザインを考える
   - カラー、余白、フォント、見出しの大きさを統一します。
4. 実装する
   - HTMLで構造、CSSで見た目を整えます。
5. 修正と改善を繰り返す
   - 文字の伝わりやすさ、見やすさ、レスポンシブ対応を確認します。
